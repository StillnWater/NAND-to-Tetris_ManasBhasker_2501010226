# Q2 – Hand encoding of Hack programs

Formats
- **A-instruction:** `0vvvvvvvvvvvvvvv` (15-bit value)
- **C-instruction:** `111a cccccc ddd jjj` (a = A/M select, comp = ALU control bits zx nx zy ny f no, dest = A D M, jump = lt eq gt)

Symbols used in Program 2: `LOOP` = 4, `END` = 9 (label addresses = ROM line of the next instruction).

| 1 | `D=A` | `1110110000010000` | `111` a=`0` comp=`110000` dest=`010` jump=`000` |
| 2 | `@3` | `0000000000000011` | `0` + 15-bit value `000000000000011` (= 3) |
| 3 | `D=D+A` | `1110000010010000` | `111` a=`0` comp=`000010` dest=`010` jump=`000` |

| 5 | `M=D` | `1110001100001000` | `111` a=`0` comp=`001100` dest=`001` jump=`000` |
